# 🤖 AIMA Python — Algoritmos de Inteligência Artificial

Implementações em Python dos algoritmos fundamentais do livro clássico **"Artificial Intelligence: A Modern Approach"** (Russell & Norvig), cobrindo as principais áreas e paradigmas de Inteligência Artificial moderna.

---

## 📌 Conteúdo e Módulos

| Arquivo | Descrição |
|---|---|
| `agents.py` | Agentes inteligentes e ambientes de simulação |
| `search.py` | Algoritmos de busca em espaço de estados (BFS, DFS, A*, busca heurística) |
| `games.py` | Algoritmos para tomada de decisão em jogos (Minimax, Poda Alfa-Beta) |
| `logic.py` | Lógica proposicional e inferência lógica de primeira ordem |
| `csp.py` | Problemas de Satisfação de Restrições (Constraint Satisfaction Problems) |
| `planning.py` | Planejamento clássico e espaço de planos |
| `probability.py` | Modelagem probabilística e redes bayesianas |
| `mdp.py` | Processos de Decisão de Markov (Markov Decision Processes) |
| `rl.py` | Aprendizado por Reforço (Reinforcement Learning e Q-learning) |
| `learning.py` | Algoritmos de aprendizado supervisionado e não supervisionado |
| `nlp.py` & `text.py` | Processamento de Linguagem Natural e análise textual |
| `utils.py` | Funções utilitárias e estruturas de dados auxiliares |
| `doctests.py` | Bateria de testes e validação das implementações |

---

## 🚀 Como Executar

Para executar os testes automatizados e validar os módulos:

```bash
python doctests.py -v
```
